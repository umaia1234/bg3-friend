# 검증 범위 — 2026-09-07

공개 소스의 검증 요약입니다. **오프라인 자동 검사**와 **개발자가 실제 게임에서 관찰한 결과**를 구분합니다. 아래 게임 관찰은 개발 환경에서의 제한된 표본이며, 모든 환경에서 동일하게 동작한다는 보장은 아닙니다. 개인 플레이 로그·스크린샷·세이브는 공개하지 않습니다.

## 확인됨: 오프라인 검사

0.2.0-rc.1 소스에서 **Windows Python 3.11.9: 337 통과·1 POSIX 전용 스킵**, **WSL Python 3.12.3: 332 통과·6 Windows 전용 스킵**을 확인했습니다. [Python 테스트](../tests/)에서 실제 GUI 처리 함수·러너를 시험하고, `lupa`로 [실제 서버 Lua](../mod/Mods/BG3Friend/ScriptExtender/Lua/Server.lua)를 모의 게임 엔진에 연결합니다.

- 세션·리비전·동료·대상 확인, 오래된 모델 결과와 명령 거절.
- 이동 의도·명령 전송·도착 확인·취소의 구분.
- 기다리기 약속 유지, 상황 변화에 따른 판단, 제한된 자동 합류.
- 지정 동료만의 전투 제어, 지연된 상태 적용, 연결·전투 종료 시 해제.
- 전투 카메라 선택과 실제 사람 캐릭터의 구분.
- 첫 만남 대화·기존 파티원 감지, 선택 저장, 합류 전 제어 금지.
- 합류 대기 취소, 선택 변경, 저장 세션 변경 뒤 일시 정지와 재개.
- 개인 스킬 등록 미리보기의 무변경, 등록·백업·설정 보존, 반복 등록의 무변경, 잘못된 경로·설정 거절.
- PAK 해시 검증, 최초 원본 보관, 설치·갱신·제거, 다른 모드 보존, 수동 변경 충돌과 실패 시 롤백.
- 첫 파일 기록 직후 별도 설치 프로세스를 강제 종료한 fixture에서, 미완료 저널을 발견한 다음 설치·제거의 무변경 거부.
- 진행 중인 모델 요청의 취소, 반복 실패 횟수 제한, Windows 소유 Job Object·POSIX 프로세스 그룹의 자손 정리와 무관한 프로세스 보존.
- Windows/WSL 동시 실행 금지, 첫 heartbeat 이전 실행 소유권 검사, 동의 해제·창 종료·설정 변경 중의 경쟁 조건.
- Windows PowerShell 5.1에서 기본 Saved Games 경로, native 우선 스킬 진단과 소스 대체 경로.

컴파일 검사와 Git 공백 검사가 통과했습니다. 설치 안내를 작성하지 않은 실행자가 문서만 따라 Windows 임시 fixture의 설치 미리보기→설치→제거 미리보기→제거를 마쳤고, 기존 게임·다른 모드·공용 Extender·세이브의 시험용 바이트 보존을 확인했습니다.

Python 3.11 이상과 `venv`, `tkinter`가 필요합니다. Ubuntu에서는 `sudo apt install python3 python3-venv python3-tk`로 준비한 뒤 프로젝트 폴더에서 실행합니다.

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -e '.[test]'
.venv/bin/python -m pytest -q
```

이 검사는 실제 게임·Codex 모델 호출·저장 파일 수정을 하지 않습니다. 게임 없이 검사를 통과하는 것만으로 게임 연동이 확인된 것은 아닙니다.

## 확인됨: Codex 스킬 등록과 시작 진단

공개 프로젝트 지침과 [시작 스킬](../.agents/skills/bg3-friend-start/SKILL.md)을 제공합니다. 등록·시작 관련 검사는 위 전체 검사에 포함됩니다. 앞선 소스 실행 버전은 기존 Windows 개인 스킬의 실제 갱신, 원본 일치, 로컬 설정 보존과 이전 설치 백업을 확인했습니다. 현재 RC는 native EXE를 우선 사용하는 경로를 추가했습니다.

기존 설치에서 Windows PowerShell 5.1과 WSL 경유 `-Action Check`가 Tk, 모드 등록, WSL Codex 로그인 준비 상태를 확인했습니다. 두 Windows 경로 구분자 표기를 정규화하고, 일반 출력과 WSL 자체 오류의 다른 인코딩을 처리합니다. 없는 배포판을 지정한 시험에서는 설정 필요 목록과 읽을 수 있는 오류를 반환했습니다. 게임·도우미가 켜져 있어도 게임 상태 파일이 오래됐으면 `waiting_save`로 구분합니다. 이 점검은 새 세이브를 불러오거나 모델 요청을 보내지 않았습니다.

스킬의 설치·세이브·동료 선택 절차는 승인된 작업을 이어가는 Codex 지침입니다. 신규 PC 전체 설치와 선택부터 플레이 완료까지의 무인 실행을 검증했다는 뜻은 아닙니다.

## 관찰됨: 앞선 개발 버전의 실제 게임

환경: Windows Steam BG3 4.1.1.7398727, DirectX 11, Script Extender v32, WSL Ubuntu-24.04, Windows Python 3.11, Codex CLI의 기존 로그인. 한 명의 사람 플레이어와 한 명의 지정 동료로 확인했습니다.

| 기능 | 실제로 관찰한 내용 | 한계 |
|---|---|---|
| 채팅과 탐험 | 미니맵 아래 한국어 입력, 실제 Astra 응답, 사람이 이동하는 동안 동료의 대기, 재합류와 도착 | 한국어 IME 조합의 모든 입력 상황이나 장시간 플레이까지 시험한 것은 아님 |
| 자동 전투 | 레이젤이 직접 이동·공격 명령 없이 이동하고 시험용 적을 처치, 전투 종료 후 제어 해제 | 단순한 적 한 명과의 한 번의 전투; Astra 전술 명령이 아닌 게임 AI |

검증에는 기존 세이브를 덮어쓰지 않았습니다. 별도로 만든 시험용 저장만 확인 뒤 정리했습니다.

## 0.2.0-rc.1 휴대용 실행 검증

Python 3.11.9·Tcl/Tk 8.6.12·PyInstaller 6.22.2로 Windows x64 ZIP을 제작했습니다. 첫 동결 실행에서 Tk 생성과 포함한 실제 PAK의 SHA-256 일치를 확인했습니다. 이후 실제 설정 화면에서 발견한 Codex 상대 경로 탐지, 작은 화면의 버튼 잘림, 실행 환경에 따른 설정 폴더 분리를 수정했습니다.

설정·설치 복구 기록의 기본 위치는 Windows의 Saved Games 사용자 폴더 아래 `BG3Friend`입니다. 새 파일을 Windows에서 작성하고 WSL에서 동일한 물리 경로로 읽어, 이 PC에서 실행 방식에 따른 경로 분리를 해소했는지 확인했습니다. 게임의 기존 IO 폴더에도 새 시험 파일이 실제 게임 경로로 기록됐습니다.

기존 Windows Codex 로그인으로 실제 합성 관찰 1회의 구조화 응답을 확인했습니다. 이 요청은 실제 게임에 명령을 보내지 않았습니다. 이번 RC의 실제 게임 설치·대화 시험은 별도 진행 중이며 위 개발 버전의 관찰을 새 배포본 전체 검증으로 대신하지 않습니다.

이 RC는 실행 파일에 전자서명하지 않았습니다. 중단된 설치는 복구 기록을 안내하고 다음 변경을 거부하며, 강제 종료·전원 중단 뒤 자동 복원 기능은 제공하지 않습니다.

## 아직 확인하지 못한 범위

새 컴퓨터의 전체 설치 과정, 모든 동료 영입 경로, 여러 사람의 게임, 여러 모드 간 상호작용, 복잡한 전투의 전술 품질, 전투 중 연결 종료와 제어 상태를 포함한 저장 복원, 지속적인 친구 같은 타이밍과 성격 일관성은 추가 시험이 필요합니다.

야영지는 대화·관찰만 지원합니다. 오버레이는 게임 창을 따라가기 때문에 일시 정지·불러오기 화면 위에도 보일 수 있습니다. 원래 게임 HUD에 삽입된 채팅 위젯은 아닙니다.
