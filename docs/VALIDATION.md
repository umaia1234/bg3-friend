## 확인됨: Codex 스킬 등록과 시작 진단

공개 프로젝트 지침과 [시작 스킬](../.agents/skills/bg3-friend-start/SKILL.md)을 제공합니다. 등록·시작 관련 검사는 위 전체 검사에 포함됩니다. 실제 Windows 개인 스킬을 RC의 native EXE 우선 경로로 갱신했고, 원본 일치·로컬 설정 보존·이전 설치 백업·반복 등록 시 무변경을 확인했습니다. 최종 설치 위치의 앱으로 Windows PowerShell 5.1 `Check`를 실행해 게임·프로필·Extender·Codex·PAK·설치 등록·로그인·기존 전송 동의 8개 항목이 모두 통과했습니다. 게임과 도우미를 정상 종료한 뒤 `Status`는 정확히 `stopped`를 반환했습니다. 실제 모델 응답은 아래 별도 게임 시험에서 확인했습니다.

기존 설치에서 Windows PowerShell 5.1과 WSL 경유 `-Action Check`가 Tk, 모드 등록, WSL Codex 로그인 준비 상태를 확인했습니다. 두 Windows 경로 구분자 표기를 정규화하고, 일반 출력과 WSL 자체 오류의 다른 인코딩을 처리합니다. 없는 배포판을 지정한 시험에서는 설정 필요 목록과 읽을 수 있는 오류를 반환했습니다. 게임·도우미가 켜져 있어도 게임 상태 파일이 오래됐으면 `waiting_save`로 구분합니다. 이 점검은 새 세이브를 불러오거나 모델 요청을 보내지 않았습니다.

스킬의 설치·세이브·동료 선택 절차는 승인된 작업을 이어가는 Codex 지침입니다. 신규 PC 전체 설치와 선택부터 플레이 완료까지의 무인 실행을 검증했다는 뜻은 아닙니다.

## 0.2.0-rc.1 휴대용 실행 검증

Python 3.11.9·Tcl/Tk 8.6.12·PyInstaller 6.22.2로 Windows x64 ZIP을 제작했습니다. 첫 동결 실행에서 Tk 생성과 포함한 실제 PAK의 SHA-256 일치를 확인했습니다. 이후 실제 설정 화면에서 발견한 Codex 상대 경로 탐지, 작은 화면의 버튼 잘림, 실행 환경에 따른 설정 폴더 분리를 수정했습니다.

설정·설치 복구 기록의 기본 위치는 Windows의 Saved Games 사용자 폴더 아래 `BG3Friend`입니다. 새 파일을 Windows에서 작성하고 WSL에서 동일한 물리 경로로 읽어, 이 PC에서 실행 방식에 따른 경로 분리를 해소했는지 확인했습니다. 게임의 기존 IO 폴더에도 새 시험 파일이 실제 게임 경로로 기록됐습니다.

최종 ZIP을 한국어와 공백이 있는 새 경로에 풀어 외부 Python/Tcl/Tk 환경 변수와 PATH 의존성을 제거한 상태로 실행했습니다. 실제 Tk 생성과 포함된 PAK 해시를 확인했고, 내부 파일 1,002개의 SHA-256이 모두 일치했습니다. 수집된 Python 모듈 206개·코드 객체 8,882개와 텍스트에서 개인 경로·인증 패턴 검출은 0건이었습니다. 의존성 고지와 빌드 명세를 포함하고 Codex·Extender·LSLib·게임 파일·세이브·개인 설정은 포함하지 않습니다.

기존 Windows Codex 로그인으로 실제 합성 관찰 1회의 구조화 응답을 확인한 뒤, **RC의 동결 앱과 실제 PAK로 설치·게임 시험**을 진행했습니다. 환경은 Windows Steam BG3 4.1.1.7398727 / DirectX 11 / Script Extender v32 / native Codex CLI / gpt-6-astra이며, 실제 게임 동작은 Computer Use로 조작했습니다.

|---|---|

이 시험에서 사용한 저장과 동료는 개발 검증용 선택이며 사용자의 기본 플레이 선택으로 등록하지 않았습니다. 대기·재합류 시험은 한 장소의 한 동료 표본입니다. 앞선 개발 버전의 단일 전투·첫 영입·새 저장 복원 관찰은 위에 따로 표시했으며, 이를 이번 RC의 새 전투 검증으로 계산하지 않습니다.

이 RC는 실행 파일에 전자서명하지 않았습니다. 중단된 설치는 복구 기록을 안내하고 다음 변경을 거부하며, 강제 종료·전원 중단 뒤 자동 복원 기능은 제공하지 않습니다.

## 아직 확인하지 못한 범위

새 컴퓨터의 전체 설치 과정, 모든 동료 영입 경로, 여러 사람의 게임, 여러 모드 간 상호작용, 복잡한 전투의 전술 품질, 전투 중 연결 종료와 제어 상태를 포함한 저장 복원, 지속적인 친구 같은 타이밍과 성격 일관성은 추가 시험이 필요합니다.

야영지는 대화·관찰만 지원합니다. 오버레이는 게임 창을 따라가기 때문에 일시 정지·불러오기 화면 위에도 보일 수 있습니다. 원래 게임 HUD에 삽입된 채팅 위젯은 아닙니다.
